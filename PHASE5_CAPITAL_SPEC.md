# PHASE5_CAPITAL_SPEC - CAPITAL_EFFICIENCY_RESEARCH (Branch B), preregistered before any Branch B performance

Label: CAPITAL_EFFICIENCY_RESEARCH. These are NEW architectures with new experiment IDs (E049). They are never presented as frozen E040 and they do not feed the 2025 decision. Because Branch A closed as TREND_REPLICATION_FAILURE, the highest classification any Branch B architecture can receive in Phase 5 is CAPITAL_EFFICIENT_WEAK_SIGNAL: an implementation of a phenomenon that failed independent replication cannot be a paper candidate.

## Universe rule (PHASE5_CAPITAL_UNIVERSE.md, generated by research/phase5_capital_universe.py; no performance input)

USDT-M perpetual present in the 2026-09-08 exchangeInfo rule snapshot with status TRADING; minimum notional <= 20 USDT; lot value (stepSize x last development close on disk, 2024-12-31) <= 5 USDT; listed on or before 2020-12-31; complete hourly history on disk for 2020-2024. Ranked by the Phase 4 as-of-2021-12-31 median daily quote turnover (reports/E043_universe/eligibility.csv). Subsets: top-N by that rank for N = 2, 3, 4, 5. Membership is fixed by these rules; Phase 4/5 signs of the selected names are disclosed but were not used.

## Signal (unchanged, frozen)

The frozen seven-vote slow-trend score in [-1, 1] on 4h bars (PHASE5_TREND_FROZEN_SPEC.md), computed by phase4_engine.signals; orders at scheduled 4h opens; hourly marks and funding; stress costs 9.05 bps per side plus actual funding. Window 2022-01-01..2024-12-31 (same as Phase 4; 2025/2026 untouched).

## Architectures (E049)

- B1/B2 (one position per asset, portfolio-level capital): target notional_i = score_i x E_t x s / N, where E_t is current portfolio equity, s the risk scalar (1.0 primary, 0.5 secondary), N the number of assets. No sub-sleeves, no breakout leg. Resizing whenever the score changes (the frozen rule), executed at the next scheduled 4h open.
- B3 score-based positioning is the same mapping (score x risk scalar); the difference from E040 is that capital is pooled at portfolio level and rounded once per asset.
- Exchange constraints: quantities rounded down to stepSize; an order is sent only if |delta notional| >= minimum notional; otherwise the difference is carried (the accumulation buffer: the desired quantity is recomputed every scheduled open, so unexecuted differences persist until they clear the minimum). Prices: hourly opens; no depth.
- Dead-band on score change: resize only if |pending score - held score| > band, band in {0, 0.10, 0.25}; 0 is the frozen behaviour.
- Volatility-target overlay: s_t = s x min(1, 20% / lagged 30-day realised volatility of the unconstrained N-asset trend portfolio); gross never above 1x. Compared with the raw exposure.
- Capital: 500, 1,000, 2,500, 5,000 USDT and an unconstrained reference (no rounding, no minimum notional) for the same N.

## Metrics per configuration

Sharpe, CAGR, max drawdown, annual turnover and cost, mean absolute target-vs-achieved weight error, tracking error (annualised std of daily achieved minus unconstrained returns), skipped-order fraction (scheduled opens where a resize was desired but not executable), Sharpe retention (achieved / unconstrained), drawdown difference.

## Classifications (fixed)

- NOT_OPERATIONALLY_FEASIBLE: skipped-order fraction > 25% or tracking error > 50% of unconstrained volatility at the stated capital.
- FEASIBLE_BUT_EDGE_DESTROYED: feasible but Sharpe retention < 50%.
- CAPITAL_EFFICIENT_WEAK_SIGNAL: feasible, retention >= 50%, but the unconstrained N-asset trend portfolio itself has Sharpe < 0.5 or drawdown < -40%, or Branch A did not replicate (the Phase 5 cap).
- CAPITAL_EFFICIENT_RESEARCH_PROMISING: feasible, retention >= 75%, unconstrained Sharpe >= 0.5, drawdown > -40%, and Branch A at least TREND_CROSS_COHORT_WEAK_SIGNAL.
- PAPER_FEASIBILITY_CANDIDATE: as above with Branch A at least RESEARCH_PROMISING and a separate freeze. Not reachable in Phase 5.

Multiplicity: two new architectures (score-based portfolio positioning; volatility-target overlay), cumulative 388 economic/architecture hypotheses after they run; dead-band, buffer and capital levels are execution diagnostics.

## Amendment 1 (2026-09-09, before the valid E049 run)

The first E049 run (E049_20260909T152740) is SUPERSEDED: the simulator resized every position at every scheduled 4h open to follow equity drift, contrary to the architecture text above ("resizing whenever the score changes"), inflating turnover to 107-154x per year and costs to 10-14% of capital per year. Corrected rule: an order is generated only when (a) the score changes, (b) the volatility-target scalar has moved by more than 10% since the last resize of that asset, or (c) a previous order was below the minimum notional and is still pending (the accumulation buffer). Skipped-order fraction counts score-change events whose first attempt is below the minimum; pending_order_hours counts hours spent waiting. No other change; classification rules unchanged.
